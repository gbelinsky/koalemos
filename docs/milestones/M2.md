# Milestone 2: UI Foundation + Simple Agent Loop

**Status:** Planning → Executing
**Start Date:** 2025-10-28
**Target:** Chat with AI works (text-only, no screenshots)

---

## Goal

Build a generic chat interface that works with ANY routine, proving the complete architecture flow without the complexity of screenshots, parsing, or wireframe-specific features.

**Success Criteria:**
- ✅ User can navigate to home page
- ✅ Click "Start Chat" → opens modal, starts routine
- ✅ Chat interface displays messages
- ✅ User can type and send messages
- ✅ AI responds with text messages
- ✅ Multi-turn conversation works
- ✅ Routine status displays correctly
- ✅ No errors, smooth UX

---

## Strategy

**Component-by-Component, Bottom-Up:**
1. Build in dependency order (leaves first)
2. Port working components where possible
3. Break monolithic components into smaller pieces
4. Test each component in isolation
5. Integrate progressively

**Port vs Rebuild:**
- **Port:** UserInputComponent, core_components, layouts (proven code)
- **Rebuild:** MessageCardsComponent → smaller card components (break monolith)
- **New:** ChatPanel, pages (composition of ported/rebuilt components)

---

## Component Architecture

### Dependency Tree

```
Level 0: Foundation
├── core_components.ex (Phoenix defaults)
├── layouts (root, app)
├── MarkdownHelper
└── app.js (minimal - LiveView + ScrollToBottom)

Level 1: Atomic Message Cards
├── MessageCards.UserCard (displays user message + images)
├── MessageCards.AssistantCard (displays AI response)
├── MessageCards.ErrorCard (displays errors)
└── MessageCards.ImageGallery (reusable image display)

Level 2: Input & Feed
├── UserInputComponent (text + image input) [PORT from Flo]
└── MessageFeed (scrollable message list, uses Level 1 cards)

Level 3: Chat Panel
└── ChatPanel (combines MessageFeed + UserInputComponent)

Level 4: Pages
├── HomePage (landing page at /)
├── StartSessionModal (routine selector modal)
├── RoutineChatLive (main chat page at /chat/:routine_id)
└── Router updates

Level 5: Backend
├── TemplatedSemanticAgent subroutine [PORT from Flo]
└── TestLens updates (add context, remove tools for M2)
```

### Component Responsibilities

**MessageCards.UserCard** (~100 lines)
- Render user message text
- Display attached images as thumbnails
- Expand/collapse images
- Props: `message, expanded_images`

**MessageCards.AssistantCard** (~150 lines)
- Render AI response text
- Markdown formatting
- Props: `message`

**MessageCards.ErrorCard** (~50 lines)
- Display error messages
- Props: `error_message`

**MessageCards.ImageGallery** (~100 lines)
- Reusable image thumbnails
- Click to expand
- Used by UserCard (and later ToolResultCard)
- Props: `images, card_id, expanded_images`

**MessageFeed** (~150 lines)
- Load initial messages from Observer events
- Subscribe to new messages via PubSub
- Render appropriate card type per message
- Auto-scroll to bottom
- Props: `routine_id, messages`

**UserInputComponent** (~383 lines) - PORT from Flo
- Text input field
- Image upload (drag-and-drop)
- Image preview/removal
- Sends `{:user_input_submitted, %{text, images}}` to parent
- Already modular, well-tested in Flo

**ChatPanel** (~200 lines)
- Combines MessageFeed + UserInputComponent
- Handles message submission
- Manages message list state
- Props: `routine_id`

**HomePage** (~100 lines)
- Landing page at `/`
- "Start Chat Session" button
- Opens StartSessionModal

**StartSessionModal** (~150 lines)
- Select routine (hardcoded "Test Chat" for M2)
- Generates routine_id
- Navigates to `/chat/:routine_id`
- Future: routine selector dropdown

**RoutineChatLive** (~300 lines)
- Main chat page at `/chat/:routine_id`
- Mounts with routine_id from URL
- Starts routine via EngineManager
- Subscribes to routine events via PubSub
- Uses ChatPanel component
- Displays routine status
- Error handling

**TemplatedSemanticAgent** (~150 lines) - PORT from Flo
- Subroutine implementing agent loop
- Steps: ChatUserInput → LensRendering → LLMRequest → ResponseParsing → loop
- No tool calls for M2 (just conversation)

**TestLens** (~50 lines) - UPDATE existing
- Add text context (system instructions)
- Remove tool definitions for M2 (add back in M3+)
- Minimal viable lens

## Integration Points

### PubSub Topics

**Routine Events:**
- Topic: `"routine_events"`
- Events: `{:routine_event, %{routine_id, event_type, ...}}`
- Used by: MessageFeed (to get new messages)

**UI Updates:**
- Topic: `"ui_updates:chat:#{routine_id}"` (future)
- Events: Custom updates for specific UI needs
- Used by: N/A in M2

### Event Flow

```
User types message
  ↓
UserInputComponent emits {:user_input_submitted, %{text, images}}
  ↓
ChatPanel receives event
  ↓
ChatPanel sends to parent LiveView (RoutineChatLive)
  ↓
RoutineChatLive sends to routine via... (TBD: direct call or PubSub?)
  ↓
Routine executes ChatUserInput step
  ↓
Observer broadcasts {:routine_event, %{event_type: "step_completed"}}
  ↓
MessageFeed receives event via PubSub
  ↓
MessageFeed updates message list
  ↓
User sees AI response
```

### State Management

**RoutineChatLive:**
- routine_id (from URL)
- routine_status (:running | :completed | :error)
- error_message (if error occurs)

**ChatPanel:**
- messages (list of message maps)
- Receives updates from MessageFeed child component

**MessageFeed:**
- messages (list, synced from Observer events)
- expanded_images (MapSet of expanded image IDs)
- Subscribes to PubSub routine_events

**UserInputComponent:**
- user_input (text)
- images (list of uploaded images)
- Internal state only

### Manual Testing Checklist

**User Journey:**
1. Navigate to `/`
2. Click "Start Chat Session"
3. Modal opens
4. Click "Start" in modal
5. Navigate to `/chat/:routine_id`
6. Chat page loads
7. Type message "Hello"
8. Press Enter
9. Message appears in chat
10. AI thinks (loading state?)
11. AI response appears
12. Type follow-up message
13. AI responds again
14. Conversation continues smoothly

**Error Cases:**
- Invalid routine_id in URL
- Routine fails to start
- LLM API error
- Network error
- Malformed message
